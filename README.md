# Offline UPI Payments

A UPI payment system that works without internet connectivity. Send and receive payments offline!

## Features

- Offline UPI transactions
- Secure vault storage
- Transaction history
- No internet required

## How It Works

This system enables UPI payments without an active internet connection by using a secure local vault and synchronization mechanism.

## Quick Start

```bash
# Run the application
python main.py
```
